# 🚀 Space Defender 

Python ve **PyGame** kütüphanesi kullanılarak Nesne Yönelimli Programlama (OOP) prensiplerine uygun şekilde geliştirilmiş retro arcade uzay savunma oyunu.

---

## 🎮 Oyun Özellikleri

- **Ana Menü & Arayüz:** Oyun başlangıcında tuş kontrollerini ve rekor skorunu gösteren dinamik karşılama ekranı.
- **Nesne Yönelimli Oyun Mimarisi (OOP):** Oyuncu gemisi, mermiler, düşmanlar ve skor takibi için modüler sınıf yapıları.
- **Kalıcı Yüksek Skor (File I/O):** Elde edilen en yüksek skor `high_score.txt` dosyasına otomatik kaydedilir.
- **Dinamik Efektler:** Motor alevi animasyonu, hareketli arka plan yıldızları ve görsel detaylar.
- **Duraklatma (Pause) Desteği:** Oyun esnasında `P` tuşu ile oyunu dilediğiniz an duraklatma imkanı.

---

## ⌨️ Oyun Kontrolleri

| Eylem | Tuş Kombinasyonu |
| :--- | :--- |
| **Sola / Sağa Hareket** | `A` / `D` veya `Sol Ok (←)` / `Sağ Ok (→)` |
| **Ateş Etme** | `SPACE` (Boşluk Tuşu) |
| **Oyunu Duraklat / Devam Et** | `P` |
| **Yeniden Başlat (Game Over)** | `R` |
